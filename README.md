# AlterFox

### Readme (EN)
Alterfox is a Firefox Addon that can be used for Markdown Viewing or Alternet Browsing.  
It supports viewing any network .md files and its unique styling ACS system.

### Прочти меня (RU)  
AlterFox это расширение Firefox, позволяющее просматривать сетевые Markdown файлы и предназначенное  
для сети АльтерНет. Оно поддерживает уникальный стандарт стилей ACS.
